# Skippy configuration

Whenever public configuration changes, update the public docs in the same
change. Keep the [serving configuration guide](../../docs-site/content/configuration/index.mdx)
and [option reference](../../docs-site/content/configuration/reference.mdx)
consistent with the supported settings, defaults, validation rules, and
examples. Update the [CLI reference](../../docs-site/content/cli.mdx)
when the change affects CLI flags or command behavior.
