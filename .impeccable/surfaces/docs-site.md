# Skippy documentation site

## Direction contract

**THESIS:** A fast engineering handbook for getting a model serving, then
understanding the machinery beneath it. It refuses a promotional landing page
or a dashboard disguised as documentation.

**OWN-WORLD:** A light, high-contrast reading surface anchored by the supplied
black kangaroo wordmark. Restrained neutrals, one cool blue interaction color,
workhorse sans typography, and mono only for code, configuration, and measured
values. Nextra's familiar navigation remains recognizable.

**STORY:** An engineer lands on a runnable quickstart, serves one model, then
moves into model operations, explicit pipeline stages, caching, configuration,
and contribution contracts with progressively deeper detail.

**FIRST VIEWPORT:** Documentation chrome with the Skippy wordmark in the upper
left, search immediately available, a concise “Serve your first model” opening,
and a complete copyable command sequence before any conceptual deep dive.

**FORM:** Code-led Read surface using the category-standard Nextra docs theme,
played at full fidelity. `seed: none (pinned)` — “I want to use nextra on
cloudflare workers” and the supplied Skippy logo pin the framework and brand.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope

Production-ready documentation site, responsive on desktop and mobile, with
static Pagefind search and Cloudflare Workers deployment configuration. Public
content covers Getting Started, Running Models, Pipeline Parallelism, KV
Caching, Configuration Reference, and Contributing. MeshLLM product behavior,
historical plans, and internal qualification documents remain out of scope.
